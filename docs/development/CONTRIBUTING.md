# Contributing to OptiGuide

Thank you for contributing to OptiGuide.

## Engineering Rules
1. **Never commit real secrets** or `.env` files.
2. **Always run tests** (`.\scripts\run-tests.ps1`) before opening a pull request.
3. **Preserve medical disclaimers:** OptiGuide is a preliminary screening tool and must not prescribe lenses independently.
4. **Adhere to clean architecture:** Separate database queries from FastAPI route handlers.
