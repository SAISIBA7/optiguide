# OptiGuide — Git & Branching Workflow

## Branch Conventions
- Main branch: `main`
- Workstream 1: `feature/phase-1-architecture`
- Workstream 2: `feature/phase-1-frontend`
- Workstream 3: `feature/phase-1-backend`
- Workstream 4: `feature/phase-1-contracts-qa`

## Pull Request Guidelines
1. Branch from `main`.
2. Follow Conventional Commits: `feat(...)`, `fix(...)`, `docs(...)`, `test(...)`.
3. Ensure CI checks pass on GitHub Actions.
